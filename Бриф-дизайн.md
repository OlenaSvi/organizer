# Бриф на дизайн: «Организатор»

## 1. Что это

Личный органайзер для одного человека. Одна HTML-страница без сервера, открывается двойным кликом, все данные хранятся в браузере. Пять экранов-«ракурсов» на одну и ту же жизнь: Сегодня · Календарь · Карта · Матрица · Список. Язык интерфейса — русский.

Нужен визуальный дизайн (цвета, типографика, отступы, формы). Логика, состав экранов и все формулировки — готовы и не меняются.

## 2. Пользователь

Елена: не технарь, ADHD, жизнь в трёх странах (Амстердам, Кипр, Израиль). Пользуется на компьютере и айпаде.

Что это значит для дизайна:

- **Минимум визуального шума.** Каждый лишний цвет, рамка и значок — налог на внимание. Один акцентный цвет, остальное тихое.
- **Ясная иерархия с первого взгляда:** что главное на экране — видно без чтения.
- **Ничего не кричит и не дёргается.** Без агрессивных бейджей, пульсаций, конфетти.
- **Крупные зоны нажатия,** просторная вёрстка.

## 3. Пять принципов продукта — и что каждый требует от дизайна

1. **Разные перспективы.** Пять экранов — одна семья: общие карточки, чипы, кнопки, попапы. Экраны различаются раскладкой, не стилем.
2. **Реализм: 3/5/7 дел в день.** Счётчик «N из 5» — спокойный элемент, не прогресс-бар достижений. Переполнение — мягкое предупреждение, не тревога.
3. **Рутина — каждый день, отдельно от дел.** У рутины свой тихий характер: строки, точки дней недели, «2 из 5 за неделю». Без серий-стриков и наказаний за пропуск.
4. **Приложение без вины.** ЗАПРЕЩЕНО: красный цвет как сигнал опоздания, слово «просрочено», восклицательные знаки, иконки-предупреждения у дат. Прошедшие даты выглядят так же спокойно, как будущие: «вчера», «3 дня назад», «срок прошёл».
5. **Порядок.** Одинаковые вещи выглядят одинаково везде: одна форма даты, один вид чипа сферы, один стиль кнопки.

## 4. Словарь (не менять, дизайн должен ему соответствовать)

Настоящие формулировки из приложения: «Предлагаю», «взять», «не сегодня», «в предложения», «важное, но не горит», «не успели вчера», «ждёт», «срок прошёл», «Разобрать», «шаг 2 из 3», «в очереди ещё 3 дела», «На сегодня встреч нет», «Это не „ничего"». Тон — ровный, дружелюбный, без канцелярита и без сюсюканья.

## 5. Инвентарь экранов и компонентов

**Шапка (общая):** 5 вкладок; «Я сейчас: [место]»; оранжевая пилюля «Разобрать · N» (появляется при делах без сферы); шестерёнка настроек; главная кнопка «＋ Добавить дело».

**Сегодня** — главный экран, вписан в высоту окна без прокрутки страницы. Двухколонная сетка: слева широкая колонка «Дела» (счётчик N из 5, карточки взятого, зачёркнутые сделанные, блок «Предлагаю» со строками и кнопками «взять»/«не сегодня», кнопка-поиск «＋ Найти или записать»); справа узкая колонка: «Рутина» (строки с точками недели) и «Аппоинтменты» (строки «16:00 · название»). Длинная колонка прокручивается внутри себя.

**Календарь:** режимы день/неделя/месяц; ячейки дней; элементы с цветной полоской слева (цвет = вид дела) и двумя фонами (со временем / к сроку); легенда цветов; перетаскивание на другой день.

**Карта:** SVG-майндмап из центра «Я»; 4 оси (сферы, места, люди, «что это»); ветки-круги с числом дел; листья дугами вокруг раскрытой ветки (без ограничения количества); под картой — строки дел раскрытых веток; зум и панорама.

**Матрица:** 2×2 (строки — срочность, столбцы — важность); клетка «Несрочное важное» выделена как главная; перетаскивание между столбцами.

**Список:** строка поиска + выпадающий фильтр; плоские строки: галочка, название, чипы, дата справа.

**Попапы:** просмотр дела (только чтение + «Редактировать»), редактор (поля и чипы), создание, настройки, «Разобрать». Закрытие — крестик в правом верхнем углу.

**Мелкие компоненты:** галочка-круг; чип сферы (цветной, полупрозрачный фон); чип-метка (место 📍, человек 👤, дата, «шаг 2 из 3», «неважное»); кнопки primary / ghost / текстовая-ссылка; сегментные переключатели (день|неделя|месяц); пунктирная кнопка «＋ …»; зачёркнутая строка сделанного; пустые состояния с объясняющим текстом.

## 6. Технические рамки

- Всё оформление — CSS в том же файле. Цвета собраны в переменные, менять нужно их:
  `--bg --panel --ink --dim --line --accent --accent-soft --warm --warm-soft --good --good-soft --r --shadow`
- **Обязательны светлая и тёмная темы** (тёмная уже есть, перекрашивается теми же переменными).
- Шрифты: системные (-apple-system / SF Pro) или Google Fonts с системным запасным — файл должен работать без интернета.
- Первичны компьютер и айпад (альбомный). На узком окне колонки «Сегодня» складываются в столбик — это уже свёрстано.
- Никакого изменения разметки поведения: только вид. Данные пользователя не затрагиваются.

## 7. Опробованные направления и референсы

Три характера уже показаны заказчице (файл «Дизайн-варианты.html»), решение пока не принято:

1. **«Тихая бумага»** — тёплый бумажный фон, терракотовый акцент, заголовки с засечками (дух Things 3 / бумажного ежедневника).
2. **«Чистый рабочий»** — белый, собранный, один синий акцент, чёткие карточки (дух TickTick / Todoist).
3. **«Мягкий цвет»** — кремовый фон, у каждой области свой тихий оттенок, крупные скругления (дух Sunsama).

Референсы по духу: Things 3 (тишина), Sunsama (спокойный ритуал), Structured (день у людей с ADHD), MindNode (мягкие ветки карт), Finch (теплота без вины). Антиреференс: плотные серые дашборды (Notion-таблицы, Jira).

## 8. Что нужно на выходе

1. Палитра: значения для всех переменных из п. 6, светлая и тёмная.
2. Типографика: шрифт(ы), размеры/насыщенность для заголовка экрана, названия дела, метки-подписи (сейчас: 12px, капс, разрядка), мелкого пояснения.
3. Скругления, отступы, тени — одной системой.
4. Стили компонентов из п. 5 (карточка, строка, чип, три вида кнопок, попап, пустое состояние) в выбранном характере.
5. Цветовая логика меток: сферы — палитра из ~8 различимых тихих цветов; виды дел — 4–6 цветов для полосок календаря и веток карты.

## 9. Чего НЕ делать

- Не добавлять функции, экраны и тексты — только внешний вид.
- Не вводить красный как сигнал «опоздала» и любую символику вины/срочности-паники.
- Не делать геймификацию: очки, серии, награды, конфетти.
- Не уплотнять: воздух — часть функциональности.
- Не анимировать без необходимости; максимум — мягкие переходы 150 мс.
