# Handoff: визуальный редизайн «Организатора» — тема «Ясный синий»

## Обзор
Новый визуальный дизайн личного органайзера Елены (одностраничный HTML без сервера, данные в localStorage). Пять экранов: Сегодня · Календарь · Карта · Матрица · Список + попапы. Логика, состав экранов и все тексты в приложении УЖЕ ГОТОВЫ — задача только перекрасить и оформить.

## Про файлы дизайна
`Организатор — Сегодня.dc.html` (+ `support.js` рядом) — **дизайн-референс в HTML**, а не производственный код. Открывается двойным кликом в браузере. Сверху вниз: тёмные версии всех экранов (9a–9g), Карта (8a), Список (7a), Матрица (6a), Календарь (5a), выпадающие списки (4a), попапы (3a), гайд с палитрой и компонентами (2a), светлый экран «Сегодня» (1a). Задача — **применить это оформление к существующему файлу приложения**, не перенося разметку из референса.

## Точность
**Hi-fi.** Цвета, размеры, радиусы, шрифты и отступы финальные — воспроизводить точно.

## КРИТИЧЕСКИЕ ПРАВИЛА (из брифа заказчицы)
1. **Только внешний вид.** Не менять разметку поведения, тексты, состав экранов и функций. Данные пользователя не трогать.
2. **Ничего не удалять.** Элемент есть в коде, но нет в макете → оформить по паттернам ниже (выбор из 2–4 → сегментный переключатель; вкл/выкл → тумблер; список → строки с «›»; действия → кнопки).
3. **Без вины:** НИКОГДА красный как сигнал опоздания, слово «просрочено», восклицательные знаки, иконки-предупреждения у дат. Прошедшие даты выглядят так же спокойно, как будущие («срок прошёл», «3 дня назад»).
4. Без геймификации, конфетти, пульсаций. Анимации — только мягкие переходы **до 150 мс**.
5. Воздух — часть функциональности, не уплотнять.
6. Всё оформление — CSS-переменные в том же файле (см. `tokens.css`), тёмная тема перекрашивается только их значениями.

## Типографика
Шрифт: **Manrope** (Google Fonts, веса 400/500/600/700), фоллбек `-apple-system, sans-serif`. Файл должен работать без интернета → подключить с системным запасным.
- Заголовок экрана: 22px / 700
- Заголовок панели: 17px / 700
- Название дела: 16px / 500 (в компактных строках 15px / 500)
- Метка-подпись: 12px / 600 / КАПС / letter-spacing 0.1em / --dim
- Мелкое пояснение: 13px / 400 / --dim
- Числа и даты: `font-variant-numeric: tabular-nums`

## Формы и отступы
Радиусы: 6 чип-время · 8–10 кнопки/контролы · 12 строки · 14 панели/попапы · 999 пилюли. Отступы шаг 4: 8/12/16/20/24 (панель 24, между панелями 20, внутри строки 12–16). Зоны нажатия ≥ **44px** (вся шапка ровно 44px высотой).

## Сферы (8 тихих цветов)
Чип сферы: текст = цвет, фон = тот же цвет 12–14% (тёмная тема: светлее тон, 16–20%). Форма: пилюля 999, 12px/600, padding 5px 10px, inline-flex, line-height 1.
- Мама #bf7a35 (тёмная #d99a55) · Быт #4a6fb5 (#7499d6) · Йони #8a72ab (#a98fd0) · здоровье ментальное #b1746f (#d09490) · бюрократия #7d9a6f (#9cbb8e) · Другое #7c8794 (#98a3b2) · запас #a08a4a (#c0a968) · запас #4f8fa0 (#74aebf)
Имена сфер задаёт пользователь — цвета привязаны к слоту, не к имени.

## Виды дел: 6 видов, цвет + иконка
Иконки — единый штриховой стиль: viewBox 16×16, stroke 1.5, round caps/joins, `stroke=currentColor`/цвет вида, fill none. SVG-код каждой — в `icons.html`.
- **аппоинтмент** (часы) #1f5cff — фон элемента календаря --accent-soft («со временем»)
- **сходить / съездить** (ноги) #4f8fa0
- **выбрать-купить** (кошелёк) #a08a4a
- **идея** (лампочка) #8a72ab
- **рутина** (таблетка) #7d9a6f
- **сделать** (разводной ключ) #7c8794
Элемент календаря: цветная полоска слева 3px (цвет = вид), фон: голубой --accent-soft если со временем, серый #f0f2f8 если к сроку. Тёмные цвета видов = как у сфер выше (#5b8aff для аппоинтмента).

## Чипы-метки (единый вид с чипами сфер!)
Место: контурная пилюля (1px --line), иконка-пин **#b5605c** + текст #59647c, 12px. Человек: то же с иконкой-человеком currentColor. Вид дела: то же с иконкой вида. Дата — НЕ чип: голый текст 13px --dim справа, формат «22 авг · 4 дня назад» / «28 авг · через 2 дня» / «сегодня» / «без срока». Шаги: пилюля --accent-soft, текст --accent, «шаг 1 из 2».

## Интеракции
Ховеры: строки → фон --bg; кнопки → чуть темнее/плотнее фон; всё `transition: 150ms`. Никаких движений макета, пульсаций, автоанимаций. Драг: календарь (на другой день), матрица (между клетками) — стили «в руке»/цели выше.

## Состояния и словарь
Использовать ТОЛЬКО существующие формулировки приложения: «Предлагаю», «взять», «не сегодня», «в предложения», «важное, но не горит», «не успели вчера», «ждёт», «срок прошёл», «Разобрать», «шаг 2 из 3», «в очереди ещё 3 дела», «На сегодня встреч нет», «Это не „ничего"». «важное, но не горит» — зелёным --good; «неважное» — #a7aebd; остальные статусы — --dim.
