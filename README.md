# Организатор

Личный органайзер. Одна HTML-страница, без сервера и без интернета.
Данные хранятся в браузере.

## Как открыть

Двойной клик по **`Организатор.html`**.

## Как менять

Правим **только** файлы в `src/`, потом собираем:

```bash
./build.sh        # склеить и проверить синтаксис
./test/run.sh     # прогнать все проверки
```

`Организатор.html` — результат сборки, руками его не редактируем:
следующая сборка перезапишет.

## Как дать посмотреть по ссылке

```bash
./share.sh        # готовит build/share.html
```

`Организатор.html` — цельный документ, а страница по ссылке оборачивается
в свой каркас. `share.sh` снимает наши теги `<html>/<head>/<body>`,
оставляя только их содержимое. Публикуется `build/share.html`.

## Где что лежит

| Путь | Что это |
|---|---|
| `src/` | исходники приложения (6 частей) |
| `test/` | проверки и поддельный DOM для них |
| `share.sh` | готовит версию для публикации по ссылке |
| `design/` | дизайн-пакет и макеты |
| `ARCHITECTURE.md` | как устроено и почему — читать перед правками |

## Данные

Настройки → **Данные** → «Сохранить в файл» делает копию всех дел.
Это единственный способ перенести их в другой браузер или на другой
компьютер. Стоит делать перед чисткой браузера.
